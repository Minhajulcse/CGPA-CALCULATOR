# DIU Advanced CGPA Calculator

Offline-first PWA CGPA calculator for DIU students.

## Added features
- Major vs Non-Major course classification
- Overall, Major and Non-Major CGPA breakdown
- Previous Major/Non-Major CGPA and credit inputs for full historical analysis
- Semester-wise Major/Non-Major CGPA summary
- Grade distribution table by category
- Academic insights: course count, failed courses, highest/lowest grade point
- Degree credit progress tracker with editable total degree credits
- Major/Non-Major category included in CSV export/import
- Major/Non-Major category included in printable transcript
- Local save status and reset-saved-data control
- Backward-compatible import for older CSV/localStorage data
- Runtime caching for Chart.js so the chart can continue working offline after it has been loaded once online

## Run
Open `index.html` in a browser, or serve the folder from a local web server for full PWA/service-worker behavior.
